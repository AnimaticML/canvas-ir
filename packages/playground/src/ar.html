AR-стол

Размер — сторона внешнего чёрного квадрата, без белого поля.

Размеры по ID

Снимки содержат изображение камеры. Хранятся только в памяти этой вкладки: до 5 кадров и 32 МБ. Экспортируются на устройство, автоматически никуда не отправляются.

Дополнительные настройки

Руки: GPU при поддержке устройства

Ручная привязка: прямоугольник 60×40 см. Телефон должен оставаться неподвижным.

Перетащите центр, край ширины, край глубины или ручку поворота. Сетка: 5 см; красная ось X, синяя Z. Пунктир — исходная плоскость.

Диагностическая коррекция наклона

Не меняет исходную оценку. После изменения нужна повторная настройка касания.

Маркеры для стола

DICT_4X4_50, разные ID 0, 1 и 2. Каждый код — 6×6 клеток вместе с чёрной рамкой. Полностью закрасьте чёрные клетки, вокруг оставьте белое поле. Размеры кодов могут различаться: укажите их по ID в настройках. Если клетка 5 мм, внешняя рамка 6×6 клеток имеет сторону 3 см — этот размер установлен по умолчанию.

Положите коды по краям рабочей области и покажите их вместе. Начало координат — центр первого принятого маркера с наименьшим ID. Поле можно перемещать за пределы маркеров. После привязки можно перекрывать отдельные коды, но нельзя двигать бумагу.

Измерьте сторону чёрного квадрата и введите её в настройках. При печати выберите масштаб 100% и проверьте размер линейкой.
