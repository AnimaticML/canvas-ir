Маркеры для вашего стола

DICT_4X4_50 · ID 0, 1 и 2. У каждого кода 4×4 ячейки данных и чёрная рамка толщиной в одну ячейку: всего 6×6.

На бумаге в клетку аккуратно закрасьте чёрные ячейки полностью. Вокруг оставьте белое поле хотя бы в одну ячейку. Все маркеры должны иметь одинаковую измеренную внешнюю сторону чёрной рамки. Используйте разные ID, ровный свет и плоскую бумагу.

Разложите маркеры произвольно вокруг рабочей области. Начните с совместной видимости всех трёх и держите телефон спокойно около секунды. Можно добавлять маркеры по цепочке, но каждый новый должен быть виден вместе с уже известным. Затем зафиксируйте карту. Первый маркер задаёт центр и оси стола 60×40 см.

Печать: масштаб 100%, без подгонки. Проверьте линейкой сторону чёрного квадрата после печати; введите её в настройках.
